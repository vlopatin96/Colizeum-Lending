# COLIZEUM Речица

Лендинг компьютерного клуба, страница акций и мини-бэк-офис (сертификаты, корпоративные карты, СМС-рассылки через SmartDelivery, чёрный список, управление акциями).

Статический проект на HTML/CSS/JS. Локальный запуск: `python3 -m http.server 8765`, затем http://localhost:8765/

- `index.html` — главная
- `akcii.html` — акции
- `admin.html` — бэк-офис
